Place the Mohamed Refaat (محمد رفعت) athan audio files here:

  normal.mp3  -> regular athan (used for Dhuhr, Asr, Maghrib, Isha)
  fajr.mp3    -> fajr athan (used for Fajr only)

File names must match exactly (lowercase). Once both files are present and the app
is rebuilt (flutter pub get + run), "محمد رفعت" will play correctly from the
muazzin selection screen.

This README only keeps the folder present for the Flutter asset bundler; it is
ignored at runtime.
